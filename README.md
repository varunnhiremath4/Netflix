# 🎬 Netflix Clone

A Netflix-inspired web interface built using **HTML5 and CSS3**. This project recreates the look and feel of Netflix's streaming platform, focusing on layout, styling, and user interface design.

## 🚀 Features

- Netflix-inspired user interface.
- Clean and modern design.
- Custom styling using CSS.
- Structured HTML layout.

## 🛠️ Technologies Used

- **HTML5** – Structure of the website.
- **CSS3** – Styling, layouts, and visual design.
